🕒 Greeting and Current Time
A simple Python program that displays a greeting based on the current hour and prints the current time in HH:MM:SS format.

📌 Features
Displays a greeting based on the current time of day.
Supports four greetings:
Good Morning
Good Afternoon
Good Evening
Good Night
Prints the current time in hours, minutes, and seconds.
Uses Python's built-in time module.


🛠️ Technologies Used
Language: Python
Module: time (built-in Python module)

🚀 Getting Started
Prerequisites
Make sure Python 3 is installed on your system.

Check your Python version:

python --version
Installation
Clone this repository or download the source code.
Navigate to the project directory.
Run the Python script: python main.py


🧠 How It Works
Imports the built-in time module.
Retrieves the current hour using time.strftime("%H").
Converts the hour into an integer.
Uses conditional statements (if, elif, and else) to select a greeting.
Retrieves and prints the current time using time.strftime("%H:%M:%S").
